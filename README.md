# RelayDock · 远程安装工作台

**远程安装应用升级版**。在运维电脑上运行的桌面客户端，使用 React 渲染界面、Electron 管理桌面权限，Go 负责业务、SQLite、SSH 和 SFTP。客户端安装包按工作站的系统和 CPU 架构选择。离线资源按远端的应用、版本、系统和 CPU 架构导入。基础包只携带客户端、应用目录和小型脚本。

## 用桌面版验收

1. 从 [验收记录](docs/VERIFICATION.md) 选择实际已生成、与你电脑平台相配的产物。开发自测包可能未签名；正式分发前需签名与目标机试装。不要用不明来源的安装包替换本地产物。
2. 启动后查看底栏的本地核心状态。左侧添加测试主机，填写地址、端口和认证；通过服务器控制台核对 SSH 指纹，再继续测试和保存。使用所管理环境允许的账号，不在真实主机上尝试未知操作。
3. 在应用目录先执行**检测**，从右侧查看进度。0.1.0 的内置写入范围为 Ubuntu 24.04 上 Mosquitto 2.1.2 的首次离线安装和本版登记实例的保留数据卸载。验收记录内有 amd64 和 arm64 的本地资源目录及试用步骤。
4. 使用终端、远端文件、部署定义、任务与日志、设置和迁移视图核对功能。旧库迁移先给一致快照做预览，不要直接打开运行中的旧库；跨平台凭据需要补录，历史任务不会重发。详见 [迁移方案](docs/MIGRATION.md)。

## 运行开发版

建议 Windows 上使用 Node 22.22 与 Go 1.26.11（`backend/go.mod` 声明工具链），在本目录执行。首次安装和打包可能需要依赖下载；所生成的程序在客户端运行时不依赖 Node、Go、.NET 或 Vite 开发服务器。

```bash
npm ci
```

```bash
npm run dev
```

`dev` 构建 Go 与本地界面，然后启动 Electron。`preview:ui` 只预览布局，没有桥接，不会连接服务器。测试和打包命令见 [执行方案](docs/EXECUTION.md)。
